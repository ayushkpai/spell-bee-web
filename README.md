# Spell bee

- Open your terminal and clone this repository
    
    First make sure you have a ssh key if you dont have go to my dotfiles repository and follow the instructions

    ```
    git clone git@github.com:ayushkpai/spell-bee.git
    ```

- Next install ruby and rails

    Also documented in dotfiles

- Add words

    ```
    touch ~/.config/spell_bee/words.txt
    ```

    Open ~/.config/spell_bee/words.txt and add whatever words you want

- To run the project

    ```
    ./bin/dev
    ```
